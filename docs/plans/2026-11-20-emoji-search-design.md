# 絵文字検索 設計

日付: 2026-11-20 / 対象: `symbol_keyboard` モジュール、`IMEService`

## 目的

絵文字パネルで、英語のキーワードから絵文字を検索できるようにする。
（例: `smi` → 😀 😃 😄 …）

## スコープ

- 検索の言語は英語のみ。日本語・読みでの検索は対象外。
- 絵文字パネルの中に検索欄を置く。変換候補への絵文字追加は対象外。
- 完全オフライン。データはアプリに同梱する。

## 使い方

1. 絵文字パネルのカテゴリタブの右端に 🔍 を置く。
2. 🔍 をタップすると、タブが検索欄に変わり、キーボードが英字（QWERTY）に切り替わる。
3. 打った文字は IME 本体ではなく検索欄に入り、入力のたびに一覧が絞り込まれる。
4. 絵文字をタップすると、通常どおり入力欄に入る。
5. ✕ をタップすると検索欄が閉じ、タブと一覧、元のキーボードに戻る。

## データ

- Unicode CLDR の英語アノテーション（名前とキーワード）を 1 ファイルにして、`symbol_keyboard` の assets に置く。
- 絵文字の文字をキーに、名前とキーワードを持つ。
- 最初に検索を開いたときに読み込む（起動時には読まない）。

## 検索ロジック

- 入力を小文字にして、名前・キーワードの前方一致で絞る。
- 複数語は AND。
- 名前に一致するものを、キーワードのみの一致より上に並べる。
- 0 件のときは「一致なし」を表示する。

## 部品

| 部品 | 役割 |
|---|---|
| `EmojiSearchIndex` | 英語の名前・キーワードの保持と検索。画面に依存しない（単体テスト対象） |
| 検索用データファイル | CLDR 英語アノテーション |
| 検索欄 UI | `EditText` と ✕ ボタン。タブと同じ位置で表示を切り替える |
| 入力の振り分け | 検索中は英字キーボードの入力を検索欄へ回す。`floating_dictionary` の `onInputTarget` と同じ仕組みを使う |

変更が入る既存コード:

- `symbol_keyboard/.../CustomSymbolKeyboardView.kt`（検索欄の表示切り替え）
- `app/.../ime_service/IMEService.kt`（検索中の入力の振り分け）
- `symbol_keyboard/src/main/res/layout/symbol_keyboard_main_layout.xml`（検索欄の追加）

## エラー時の動き

- データ読み込みに失敗したら、検索欄は出さず、今までのパネルをそのまま使えるようにする。
- 検索中に画面が切り替わっても、入力先が検索欄のまま残らないよう、必ず元に戻す。
