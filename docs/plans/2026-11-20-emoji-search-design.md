# 絵文字検索 設計

日付: 2026-11-20 / 対象: `symbol_keyboard` モジュール、`IMEService`

## 目的

絵文字パネルで、英語のキーワードから絵文字を検索できるようにする。
（例: `smi` → 😀 😃 😄 …）

## スコープ

- 検索の言語は英語のみ。日本語・読みでの検索は対象外。
- 絵文字パネルの中に検索欄を置く。変換候補への絵文字追加は対象外。
- 完全オフライン。データはアプリに同梱する。

## 使い方

1. 絵文字パネルのカテゴリタブの右端に 🔍 を置く。
2. 🔍 をタップすると、タブが検索欄に変わり、キーボードが英字（QWERTY）に切り替わる。
3. 打った文字は IME 本体ではなく検索欄に入り、入力のたびに一覧が絞り込まれる。
4. 絵文字をタップすると、通常どおり入力欄に入る。
5. ✕ をタップすると検索欄が閉じ、タブと一覧、元のキーボードに戻る。

## データ

- Unicode CLDR の英語アノテーション（名前とキーワード）を 1 ファイルにして、`symbol_keyboard` の assets に置く。
- 絵文字の文字をキーに、名前とキーワードを持つ。
- 最初に検索を開いたときに読み込む（起動時には読まない）。

## 検索ロジック

- 入力を小文字にして、名前・キーワードの前方一致で絞る。
- 複数語は AND。
- 名前に一致するものを、キーワードのみの一致より上に並べる。
- 0 件のときは「一致なし」を表示する。

## 部品

| 部品 | 役割 |
|---|---|
| `EmojiSearchIndex` | 英語の名前・キーワードの保持と検索。画面に依存しない（単体テスト対象） |
| 検索用データファイル | CLDR 英語アノテーション |
| 検索欄 UI | `EditText` と ✕ ボタン。タブと同じ位置で表示を切り替える |
| 入力の振り分け | 検索中は英字キーボードの入力を検索欄へ回す。`floating_dictionary` の `onInputTarget` と同じ仕組みを使う |

変更が入る既存コード:

- `symbol_keyboard/.../CustomSymbolKeyboardView.kt`（検索欄の表示切り替え）
- `app/.../ime_service/IMEService.kt`（検索中の入力の振り分け）
- `symbol_keyboard/src/main/res/layout/symbol_keyboard_main_layout.xml`（検索欄の追加）

## エラー時の動き

- データ読み込みに失敗したら、検索欄は出さず、今までのパネルをそのまま使えるようにする。
- 検索中に画面が切り替わっても、入力先が検索欄のまま残らないよう、必ず元に戻す。

## テスト

- 検索ロジックは TDD。先にテストを書く。
  - 前方一致になること
  - 複数語が AND になること
  - 名前の一致がキーワードのみの一致より上に来ること
  - 大文字小文字を区別しないこと
  - 0 件になること
- 画面と入力の振り分けは実機（Galaxy Z Fold8）で確認する。

## 未確認・リスク

- 検索中は一覧の見える高さが狭くなる。実機で収まりを確認する。
- 浮かぶキーボード・分割キーボードでも動かすかは未決定。まずメインのキーボードで実装する。
- `IMEService.kt` は約 3 万行あり、入力の振り分けの差し込み位置は実装前に確認が要る。

## 実装時の変更点（2026-11-20）

設計から次のように変えた。

- **入力方式**: IME 本体の英字キーボードへの切り替えはやめ、パネル内に簡易 QWERTY を持たせた。
  `IMEService.kt` の高さ管理を大きく触る必要があったため。`IMEService.kt` は変更していない。
- **UI**: 絵文字モードではカテゴリのタブをやめ、iOS 風に上へ検索欄（Search emoji）を置いた。
  一覧は「履歴 → 各カテゴリ」を見出し付きで1本につなぎ、縦スクロールで探す。絵文字モードでは左右スワイプによるカテゴリ切り替えもしない。
  顔文字・記号モードは今までどおりタブ。
- **データ**: CLDR の基本データに加え、国旗などは派生データ（annotationsDerived）にあるため、それも取り込んだ（肌色違いは除外、2,321 件）。
- **未対応**: 検索結果 0 件のときの「一致なし」表示。検索画面の色は標準色で、スキンには追従しない。
  浮かぶキーボード・分割キーボードでの動作は未確認。

## 実機への入れ方

デバッグビルドは署名の鍵がパソコンごとに違う（`~/.android/debug.keystore`）。
実用版を上書きするには、実用版をビルドしたパソコンで入れる（または同じ鍵を使う）。

```bash
# 実用版を上書き（設定は残る。署名が同じパソコンのみ）
./gradlew :app:installLiteGroqDebug

# 実用版と並べて入れる（別アプリ .dev。署名が違うパソコンでも可）
./gradlew :app:installLiteGroqDebug -PdevApp
```

- Groq の音声入力を使うには、`local.properties` に `groq.api.key=...` が要る（git には入らない）。
- `.dev` 版は別アプリなので、マイクの許可・設定は別になる。
